# Knowledge source register

These files are public reference materials collected for the knowledge-layer
prototype. The original URLs and intended roles are recorded here so every
retrieved chunk can cite its source.

The CISA resource is a public sample, not a de-identified internal inspection
report. Replace or supplement it with authorized project reports when they are
available. Standards that require a license should be obtained through the
official standards provider; do not ingest unauthorized copies.
